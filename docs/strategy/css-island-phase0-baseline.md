## The bleed (core finding)

`base.css` declares **bare-element globals** that are *shell* styles but hit every subtree:

- `* { border-radius: 0; box-shadow: none; transition: none }` — global hard reset
- `body { font-family: var(--font-mono) }`
- `h1`–`h6`: `font-mono`, `text-transform: uppercase`, `letter-spacing: 0.05em`, `border-bottom`, `padding/margin`
- `a` / `a:visited`: `color: var(--text-highlight)`, underline; `a:hover`: harsh invert (`ansi-white` bg / `ansi-black` text)
- `button`: cursor + `font-mono`

### Computed winner for markdown content (source-derived)

For `.markdown-body h1`: `markdown.css` (utilities layer, specificity 0,1,1) beats `base.css` bare `h1` (base layer, 0,0,1) on **both** layer order and specificity. Winner = `markdown.css` → `font-size: var(--font-size-5)`, `text-transform: uppercase` (redundant re-declaration), `border-bottom: var(--border-size-2) solid var(--primary)`.

For `.markdown-body a`: `markdown.css` wins → `color: var(--link)`, transparent bottom border, hover fills border. The harsh shell invert does **not** apply inside markdown.

**Conclusion:** markdown content is *currently* protected by specificity + layer order — but only because markdown.css re-declares almost everything. The bleed bites in **non-markdown** shell contexts (any `h1`/`a` outside `.markdown-body` gets forced uppercase mono + harsh link hover). Phase 1 moves bare globals into a shell scope so the protection is structural, not duplicative.

## Token dependency map (Phase 3 prep)

`theme.css` **natively defines** (incl. compat maps): `--bg-canvas`, `--text-primary`, `--text-highlight`, `--font-mono`, `--font-sans` (=mono), `--spacing-*`, `--radius-component: 0px`, `--surface-1/2/3`, `--primary`, `--accent`, `--border-base`, `--border-default`, graph colors.

`markdown.css` uses tokens **NOT in theme.css** — these come from Open Props and go undefined when Open Props is dropped:

| Token family | Examples used | Phase 3 action |
|--------------|---------------|----------------|
| `--text-1`, `--text-2` | text colors | map → `--text-primary` / muted |
| `--font-size-0..5` | heading + body sizes | define scale in theme.css |
| `--font-weight-6/7` | heading weight | define (or hardcode `bold`) |
| `--font-lineheight-2/3` | line height | define |
| `--font-letterspacing-1` | h1/h4 tracking | define |
| `--border-size-2/4` | border widths | map → `2px` / `4px` |
| `--size-1..10` | spacing (differs from `--spacing-*`) | map → `--spacing-*` |
| `--radius-2/3` | code/card radius | **tension**: Open Props gives nonzero; brutalist mandate = 0. Decide. |
| `--shadow-1` | card shadow | map → `none` (brutalist) |
| `--link` | link color | map → `--text-highlight` or `--ansi-cyan` |

Also `--surface-1/2`, `--primary`, `--border-base` ARE mapped in theme.css → safe.
