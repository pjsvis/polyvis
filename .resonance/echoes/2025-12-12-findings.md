## Key Learnings

### **AST-Grep vs Ripgrep**

| Tool | Strength | Use Case |
|------|----------|----------|
| **Ripgrep** | Lightning fast text search | Strings, patterns in text |
| **AST-grep** | Semantic code understanding | Code structure, ignore comments |

**Example:**
```typescript
// This comment: console.log("debug")
const actual = console.log("real");
```

**Ripgrep:** Finds both (2 matches)  
**AST-grep:** Finds only actual code (1 match) ✅
