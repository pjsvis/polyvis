Fixed-aspect monospace scalar box. Drag SCALE — the box resizes while line wraps and row count stay constant. ADR-001 · Option B.

Geometry is a pure function of --cpl, --rows, --scale. No hardcoded pixel widths.

LIVE — bound to controls
MonoBox renders monospaced text inside a bounding box whose width and height are strict functions of the character scale. Drag the SCALE control and watch the box resize while line wrapping and row count stay perfectly constant. At S=0.15 the text Greeks into an icon-sized glyph block, the stashed-document end state. Width equals characters-per-line times one ch; height equals rows times line-height times the scaled font-size. No pixel widths are hardcoded anywhere in the geometry.
