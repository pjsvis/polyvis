# Scripts: Core

This directory contains the core logic classes and reusable components for the Polyvis ecosystem.

## Contents

- **`BentoNormalizer.ts`:** Handles Markdown normalization (H1/H2 hierarchy).
- **`EdgeWeaver.ts`:** Scans content for edges (tags, wikilinks) to build the graph.
- **`Harvester.ts`:** Scans directories for semantic tags and entities.
